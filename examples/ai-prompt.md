첨부한 MP3와 원문 가사를 바탕으로 음악 플레이어용 타임라인 가사 JSON을 만들어줘.
원문 가사를 첨부하지 않았다면 음원에서 확인하되, 알아들을 수 없는 내용을 지어내지 마.

[음원과 시간]
- MP3 시작을 0초로 잡아줘. 시간은 mm:ss 문자열이 아닌 초 단위 숫자이며 소수점을 사용할 수 있어.
- 자연스러운 구절 단위로 나누고, 실제로 노래하기 시작하는 시점을 start, 구절이 끝나는 시점을 end에 넣어줘.
- 전주·간주·후주는 가사 없이 시간 공백으로 남겨줘. 다음 구절까지 앞 구절의 시간을 억지로 늘리지 마.
- 구절은 시작 시간순으로 정렬하고 서로 겹치지 않게 해줘. 반복되는 가사도 등장할 때마다 별도 구절로 넣어줘.
- 모든 구절은 0 <= start < end <= 음원 전체 길이를 만족해야 해.

[가사·발음·번역]
- original: 원문 가사. 한 구절이 화면에서 읽기 좋도록 적절히 나눠줘.
- pronunciation: 외국어 가사를 실제 노래 발음에 맞춰 한글로 표기해줘.
- translation: 노래 전체 문맥을 고려한 자연스러운 한국어 번역. 각 원문 구절과 대응시켜줘.
- 일본어는 한자의 실제 읽기를 음원으로 확인해줘. 영어와 다른 외국어도 실제로 부르는 발음을 기준으로 한글로 적어줘.
- 한국어 구절은 pronunciation과 translation을 생략해줘. 혼합 언어 곡은 구절에 맞게 처리해줘.

[확실하지 않은 경우]
- 오디오를 직접 분석할 수 없으면 분석했다고 말하거나 시간을 추측해서 완성하지 말고, 그 한계를 먼저 알려줘.
- 가사·발음·시점이 불확실하면 확인이 필요한 부분을 먼저 알려줘. 확인 후 최종 JSON을 만들어줘.

[최종 출력]
분석과 확인이 끝나면 설명이나 마크다운 코드 블록 없이 유효한 JSON만 출력해줘.
아래는 구조 예시야. 내용과 시점은 반드시 실제 음원에 맞게 바꿔줘.
{
  "schemaVersion": 1,
  "lyrics": [
    {
      "start": 12.5,
      "end": 16.8,
      "original": "君と歩いた道",
      "pronunciation": "키미토 아루이타 미치",
      "translation": "너와 함께 걸었던 길"
    }
  ]
}

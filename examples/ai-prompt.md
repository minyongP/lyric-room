분석 방법
1. 음원 전체를 확인하고, 보컬이 나오는 구간을 화면에 읽기 좋은 짧은 구절로 나눠 주세요. 원문의 언어와 문자 체계를 유지하고, 반복되는 구절도 부르는 순서대로 모두 넣어 주세요.
2. start는 구절의 첫 발음이 시작되는 시점, end는 마지막 발음이 끝나는 시점으로 잡아 주세요. 음원 시작은 0초이며, 시간은 초 단위 숫자로 적어 주세요. 예: 1분 12.5초 → 72.5.
3. 전주·간주·후주와 구절 사이의 무음은 빈 시간으로 남겨 주세요. 다음 구절까지 이전 가사의 end를 늘리거나, ‘간주 중’ 같은 문구를 가사로 넣지 마세요.
4. 구절은 start 순으로 정렬하고 서로 겹치지 않게 해 주세요. 보컬이 겹치면 같은 구간의 내용을 한 구절로 묶어 주세요. 모든 구절은 0 <= start < end <= 음원 길이를 만족해야 합니다.
5. 완성한 타임라인을 음원과 다시 비교하고, 가사 누락·반복 구간·시작과 종료 시간을 확인해 주세요. 시간은 실제로 확인할 수 있는 정밀도로 적어 주세요.

결과 형식
- 최상위 필드는 schemaVersion과 lyrics입니다. schemaVersion은 1입니다.
- lyrics의 각 항목에는 start, end, original을 넣어 주세요.
- pronunciation은 한글 발음, translation은 한국어 번역입니다. 필요 없는 필드는 생략하세요.
- 제목, 가수, 분석 설명, 신뢰도 등 별도 필드는 넣지 마세요.
- 최종 결과는 설명이나 마크다운 코드 블록 없이 JSON만 출력해 주세요. 길어서 한 번에 제공할 수 없다면 중간에서 잘린 JSON을 내보내지 말고, 먼저 나누어 작업할 방법을 알려 주세요.

오디오를 열거나 직접 분석할 수 없다면 그 사실을 먼저 알려 주세요. 곡 제목이나 기억만으로 가사와 시간을 추측하지 마세요. 알아듣기 어려운 구절이나 처리할 수 없는 부분이 있으면 해당 시간대와 필요한 자료를 알려 주세요. 추가 확인이 필요한 경우에는 JSON 대신 짧게 질문해도 됩니다.

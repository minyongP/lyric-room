[음원과 시간]
- MP3 시작을 0초로 잡아줘. 시간은 mm:ss 문자열이 아닌 초 단위 숫자이며 소수점을 사용할 수 있어.
- 자연스러운 구절 단위로 나누고, 실제로 노래하기 시작하는 시점을 start, 구절이 끝나는 시점을 end에 넣어줘.
- 전주·간주·후주와 짧은 숨 고르기 구간은 시간 공백으로 남겨줘. 다음 구절까지 앞 구절의 시간을 억지로 늘리지 마.
- ‘간주 중’ 같은 안내 문구는 가사에 넣지 마. 플레이어가 공백 길이를 보고 표시해.
- 구절은 시작 시간순으로 정렬하고 서로 겹치지 않게 해줘. 반복되는 가사도 등장할 때마다 별도 구절로 넣어줘.
- 모든 구절은 0 <= start < end <= 음원 전체 길이를 만족해야 해.

[확실하지 않은 경우]
- 오디오를 직접 분석할 수 없으면 분석했다고 말하거나 시간을 추측해서 완성하지 말고, 그 한계를 먼저 알려줘.
- 가사·발음·시점이 불확실하면 확인이 필요한 부분을 먼저 알려줘. 확인 후 최종 JSON을 만들어줘.

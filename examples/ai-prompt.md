# AI에 전달할 가사 형식

내가 제공한 가사와 시간 정보를 JSON으로 정리해 주세요. 시간은 초 단위이며 시작 시간 오름차순, 구절 겹침 없이 `0 <= start < end <= 곡 길이`를 지켜 주세요. 확인할 수 없는 시간을 정확하다고 추정하지 말고 확인이 필요하다고 알려 주세요.

형식: `{"schemaVersion":1,"lyrics":[{"start":0.3,"end":1.2,"original":"원문","pronunciation":"발음 (선택)","translation":"번역 (선택)"}]}`.

원문은 필수이고 발음·번역은 선택입니다. 앱은 이 데이터를 재생하지만 AI가 만든 시간 정보 자체의 정확성을 보장하지 않습니다.

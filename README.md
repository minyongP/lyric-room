# Lyric Room

내 MP3에 가사·사진·영상을 더해 1080p 음악 영상을 만드는 로컬 편집기입니다.

- **파일 → 음악 파일 열기**에서 MP3 한 곡을 엽니다. 최근 프로젝트는 같은 메뉴에서 전환합니다.
- 왼쪽에서 **배경 / 가사 / 플레이어 / 시각 효과**를 선택하고 오른쪽 속성을 편집합니다.
- 미리보기에서 요소를 드래그하거나 우하단 손잡이로 크기를 조절합니다. 속성의 위치·크기 항목에서도 정확히 입력할 수 있습니다.
- 가사는 JSON 파일·붙여넣기 또는 구절별 시간/텍스트 표로 수정합니다. 현재 구절이 재생 시간에 맞춰 강조됩니다.
- 프로젝트를 저장하고 다시 열거나, **영상 내보내기 → MP4 저장**으로 영상 파일을 받습니다.

## 실행

첫 검증 환경: macOS, Chromium. Node.js **22.12 이상**, FFmpeg와 ffprobe의 PATH 등록이 필요합니다. FFmpeg에는 libx264/AAC 인코더가 있어야 합니다.

```sh
# macOS에서 FFmpeg가 없다면
brew install ffmpeg

npm ci
npx playwright install chromium
npm run dev
```

브라우저에서 **http://127.0.0.1:4173**을 여세요. 서버는 이 컴퓨터에서만 접속할 수 있습니다. 앱을 사용하기 위해 계정이나 AI API 키가 필요하지 않습니다.

배포용 로컬 실행:

```sh
npm run build
npm start
```

`PORT=4180 npm run dev`로 포트를 바꿀 수 있고, `DATA_DIR=/원하는/저장/경로 npm start`로 데이터 위치를 바꿀 수 있습니다. 서버 종료는 터미널에서 Ctrl+C입니다.

## 지원 파일과 저장

- 음악: MP3 한 파일. 파일 메뉴에서 다른 프로젝트로 전환합니다.
- 배경: JPEG, PNG, WebP, H.264 MP4. 영상은 무음이며 반복 여부와 시작 지점을 설정할 수 있습니다.
- 커버: JPEG, PNG, WebP.
- 최대 파일 크기: 512MB. 음원/영상 길이 최대 2시간, 이미지 최대 8192px. 상한까지의 성능을 보장하는 것은 아닙니다.
- 원본 파일은 변경하지 않습니다. 선택한 자산은 `.local-data/projects/<ID>/assets/`에 복사합니다.
- 편집 내용은 같은 폴더의 `project.json`에 저장합니다. 새로고침/재실행 후 파일 메뉴에서 다시 열 수 있습니다.
- 완료 영상은 `.local-data/exports/`에도 남습니다. 브라우저의 MP4 저장 버튼으로 원하는 위치에 다운로드할 수 있습니다.
- `.local-data/` 전체를 복사하면 프로젝트와 자산을 함께 백업할 수 있습니다. JSON만 복사하면 미디어는 옮겨지지 않습니다.
- 저장 전 다른 음악으로 전환하면 저장/버리기/취소를 선택합니다. 저장은 자동이 아닙니다.

설치 시 의존성·브라우저를 내려받지만, 편집·재생·렌더링은 로컬에서 처리하며 미디어를 외부에 전송하지 않습니다. 폰트도 패키지에 포함합니다.

## 가사 형식

```json
{
  "schemaVersion": 1,
  "lyrics": [
    {
      "start": 12.5,
      "end": 17.8,
      "original": "바람이 머문 자리",
      "pronunciation": "발음 (선택)",
      "translation": "번역 (선택)"
    }
  ]
}
```

시간 단위는 초입니다. `start <= 현재 시간 < end`인 구절을 강조합니다. 시작 시간이 빠른 순서로 작성하고 구절을 겹치지 않게 하세요. 전주·구절 사이·후주에는 현재 가사가 비워집니다. 빈 가사 배열도 허용됩니다. AI용 형식 복사 버튼으로 외부 AI에 줄 설명을 복사할 수 있습니다. AI가 시간을 자동으로 정확하게 맞춰주는 기능은 포함되지 않습니다.

## 영상 출력

1920×1080, 30fps, H.264(yuv420p), AAC 192kbps MP4로 출력합니다. 프로젝트 스냅샷을 사용하므로 렌더 도중 편집해도 진행 중 출력은 바뀌지 않습니다. 한 번에 하나만 렌더링하며 취소 후 재시도할 수 있습니다. 처리 속도는 곡 길이·배경 영상·기기에 따라 다릅니다.

재생 조작 버튼과 편집용 선택 테두리는 출력 영상에 포함하지 않습니다. 곡 정보, 진행 바, 가사, 커버, 주파수 분석 비주얼라이저는 포함합니다. 미리보기 볼륨은 출력 음량을 바꾸지 않습니다. 영상의 조작 버튼은 감상 화면에만 표시됩니다.

현재 선 형태 시각 효과도 시간 파형이 아닌 주파수 스펙트럼 라인입니다. 임의 레이어 추가·순서 변경, 단어 단위 노래방 강조, 여러 곡 합치기, 유튜브 업로드는 포함하지 않습니다.

## 문제 해결

- 영상 출력이 비활성화되면 FFmpeg/Chromium 설치 안내를 확인하세요.
- 다른 프로그램이 4173 포트를 쓰면 `PORT`를 변경하세요.
- 가사 검증 오류가 있으면 표시된 행의 시간 또는 원문을 확인하세요. 입력 오류는 저장/출력 전에 차단됩니다.
- 배경 MP4가 열리지 않으면 H.264로 변환하세요. 모든 MP4 코덱을 지원하지는 않습니다.
- 긴 가사가 잘리면 글자 크기를 줄이거나 가사 패널을 확대하세요.
- 강제 종료된 렌더 작업은 다시 시작해야 합니다. 완료 영상은 디스크에 유지되며 기존 파일을 덮어쓰지 않습니다.

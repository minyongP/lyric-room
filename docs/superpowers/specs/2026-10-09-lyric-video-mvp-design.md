## 목적과 합의한 범위

사용자가 선택한 폴더의 MP3와 AI로 준비한 시간별 가사 데이터를 사용해 음악을 감상하고, 배경과 스타일을 편집해 한 곡짜리 영상을 저장하는 오픈소스 도구를 만든다. 첨부 이미지는 화면 구성 참고자료다.

MVP에 포함: 폴더에서 곡 선택, 재생·일시정지·탐색·볼륨, 가사 JSON 가져오기, 원문·발음·번역 표시, 사진/영상 배경, 스타일 편집, 실제 음원에 반응하는 비주얼라이저, 프로젝트 저장/열기, 1080p MP4 내보내기.

후속 범위: AI API 직접 연동, 자동 음성 인식/타임스탬프 생성, 여러 곡을 합친 영상, 자막 한 글자씩 강조, 유튜브 직접 업로드, 사용자 계정, 클라우드 저장, 설치형 앱 배포. MVP의 AI는 외부에서 정해진 JSON을 만드는 용도이며 타이밍 정확도는 입력 데이터에 달려 있다.

## 실행 방식과 대안

선택안은 로컬 웹 편집기 + 로컬 렌더링 서버다. 브라우저에서 편집하고 같은 컴퓨터의 Node.js 서버와 FFmpeg로 영상을 만든다. 개발용 설치 안내와 실행 명령을 제공한다. 첫 검증 환경은 macOS와 Chromium 브라우저다. 다른 OS 지원을 검증했다고 미리 주장하지 않는다.

브라우저 단독 방식은 시작이 간단하지만 MP4 인코딩과 긴 영상 처리에 제약이 있다. Electron 데스크톱 앱은 파일 접근이 편하지만 초기 패키징 범위가 커진다. 로컬 웹 방식으로 핵심 기능을 검증한 뒤 설치형으로 확장한다.

구현 후보는 React + TypeScript + Vite 편집기, Node.js 로컬 API, 공통 Canvas 장면 렌더러, 헤드리스 Chromium 프레임 생성, FFmpeg 인코딩이다. 버전은 구현 시 호환성을 확인해 고정한다. FFmpeg 실행 파일과 필요한 인코더를 시작 시 검사하고, 없으면 설치 안내를 보여준다. 첫 버전에서는 FFmpeg 바이너리를 저장소에 포함하지 않는다.

## 사용자 흐름과 화면

1. 첫 화면에서 음악 폴더를 선택한다. 하위 폴더의 MP3를 상대 경로로 구분해 목록에 표시한다. 폴더를 계속 감시하지는 않는다.
2. 곡을 선택하면 재생할 수 있다. 제목은 파일명에서 초기화하고 제목·아티스트·커버를 직접 수정할 수 있다.
3. 가사 JSON을 파일로 가져오거나 붙여넣는다. 적용 전 오류 위치를 표시한다. 샘플 JSON과 AI에 전달할 형식 안내를 제공한다.
4. 배경 사진 또는 영상을 선택하고 스타일을 조절한다. 변경 내용은 미리보기에 즉시 반영한다.
5. 프로젝트를 저장하거나 현재 곡을 MP4로 내보낸다. 진행률, 취소, 완료 파일 저장을 제공한다.

데스크톱 편집 화면은 왼쪽 곡 목록, 중앙 16:9 미리보기와 재생 조작, 오른쪽 가사·배경·스타일 패널로 구성한다. 작은 화면에서는 패널을 탭으로 전환한다. 기본 UI 언어는 한국어다.

영상 장면은 전체 화면 배경, 둥근 반투명 가사 패널, 하단 곡 정보 패널, 맨 아래 비주얼라이저로 구성한다. 가사는 이전/현재/다음 구절을 세로로 배치하며 현재 구절을 크게 강조한다. 각 구절은 원문·발음·번역을 표시하되 없는 필드는 공간을 차지하지 않는다. 재생 버튼, 볼륨, 편집 패널은 영상에 포함하지 않는다. 영상 하단에는 커버·제목·아티스트·진행 표시를 남긴다.

편집 가능 항목은 글자 크기와 색상, 가사 패널 투명도, 배경 흐림과 밝기, 비주얼라이저 색상이다. 임의 레이어 배치 편집기는 만들지 않는다. 긴 가사는 자동 줄바꿈과 정해진 범위 내 크기 축소로 처리하고 그래도 넘치면 내보내기 전에 경고한다. 한글·일본어·라틴 문자를 지원하는 배포 가능한 폰트를 포함하고 출처와 라이선스를 기록한다.

## 입력과 프로젝트 저장

음악은 사용자가 선택한 폴더의 MP3만 사용한다. 배경은 JPEG/PNG/WebP 또는 MP4(H.264), 커버는 JPEG/PNG/WebP를 지원한다. 배경 미지정 시 기본 그라데이션, 커버 미지정 시 기본 아이콘을 사용한다. 배경 영상은 무음이며 곡보다 짧으면 반복하고 길면 곡 종료 시 자른다. 화면 채우기 방식으로 중앙 크롭한다.

폴더 선택은 브라우저 파일 선택 기능으로 한다. 목록에서는 상대 경로로 같은 이름의 파일을 구분한다. 선택한 곡과 배경/커버만 로컬 서버의 프로젝트 자산 저장소로 복사한다. 전체 음악 폴더를 무조건 복사하지 않는다. 원본 파일은 수정하지 않는다.

프로젝트는 로컬 데이터 디렉터리에 ID별로 저장한다. project.json에는 schemaVersion, 제목·아티스트, 자산 ID, 가사, 스타일, 출력 설정을 저장한다. 자산은 프로젝트 하위 assets에 보관한다. UI에서 저장한 프로젝트 목록을 열 수 있고, 재실행 후에도 편집 상태와 자산을 복원한다. 프로젝트 JSON만으로 다른 컴퓨터로 이동하는 기능은 제공하지 않는다. 미저장 변경은 표시하며 프로젝트 전환 시 저장/버리기를 선택한다.

가사 교환 형식:

```json
{
  "schemaVersion": 1,
  "audio": "my-song.mp3",
  "lyrics": [
    {
      "start": 12.5,
      "end": 17.8,
      "original": "샘플 원문",
      "pronunciation": "선택 항목",
      "translation": "선택 항목"
    }
  ]
}
```

시간은 곡 시작 기준 초다. audio는 사용자가 곡을 확인할 힌트이며 파일 경로 실행/접근에 사용하지 않는다. schemaVersion이 없는 기존 예시도 버전 1로 받아들인다. original은 비어 있지 않은 문자열, 다른 두 텍스트 필드는 선택 사항이다. 시간은 유한한 숫자로 0 ≤ start < end ≤ 곡 길이를 만족해야 한다. 구절은 시작 시간 오름차순이고 서로 겹치면 안 된다. 잘못된 입력은 행 번호와 이유를 보여주며 기존 가사를 유지한다. 빈 가사 배열은 가사 없는 음악 영상으로 허용한다.

현재 구절의 범위는 start ≤ t < end다. 구절 사이 공백과 전주/후주에는 중앙을 비우고 이전·다음 구절은 흐리게 표시한다. 탐색하면 즉시 해당 시점으로 갱신한다. 글자는 HTML로 해석하지 않는다.

## 재생·렌더링 구조

- 프로젝트 모델/검증: 파일 형식, 기본값, 입력 검증, 저장 버전 관리.
- 자산 관리: 사용자 선택 파일 가져오기, 메타데이터, 로컬 자산 ID와 저장 경로 관리.
- 재생 컨트롤러: MP3 재생과 탐색, 현재 시간, 곡 길이 관리.
- 오디오 분석: 디코딩한 PCM으로 고정 시간 간격의 주파수 대역 에너지 데이터를 생성한다. 시간 기반 평활화를 적용해 탐색과 렌더링 순서에 영향받지 않는다.
- 장면 렌더러: 프로젝트 + 시간 + 분석 데이터 + 준비된 배경 프레임으로 동일한 장면을 그린다. 미리보기와 영상 출력에서 같은 레이아웃과 계산을 사용한다.
- 내보내기 작업: 저장 시점의 프로젝트 스냅샷을 바탕으로 프레임 생성·인코딩·취소·정리를 담당한다. 렌더 중 편집은 진행 중 영상에 영향을 주지 않는다.

미리보기는 MP3의 실제 재생 시간을 기준으로 장면을 갱신한다. 내보내기는 30fps의 프레임 번호 / 30으로 시간을 계산한다. 폰트·사진이 로드되고 배경 영상이 원하는 시간으로 탐색 완료된 뒤 프레임을 생성한다. 배경 시간은 곡 시간 modulo 배경 길이다. 시각 효과는 무작위 애니메이션이 아니라 같은 분석 데이터를 두 경로에서 사용한다.

영상은 1920×1080, 30fps, H.264, yuv420p, AAC 오디오의 MP4로 만든다. 원본 MP3를 오디오 트랙의 입력으로 사용하고 곡 길이에서 종료한다. 프레임은 스트리밍 또는 제한된 임시 버퍼로 전달하며 전체 프레임을 메모리에 쌓지 않는다. 작업은 한 번에 하나만 실행한다. 프레임 처리와 최종 인코딩 단계를 구분해 진행 상태를 표시하며 인코딩 성공 전에는 완료로 표시하지 않는다. 렌더 속도는 기기에 따라 달라지고 실시간보다 빠르다고 보장하지 않는다.

## 오류와 로컬 실행 경계

지원하지 않는 파일, 디코딩 실패, 빈 음악 폴더, 잘못된 가사, 파일 저장 실패, 렌더링 실패를 각각 사용자에게 설명한다. 실패한 작업은 편집 상태를 유지하며 다시 시도할 수 있다. 취소 시 하위 프로세스를 종료하고 해당 작업 임시 파일을 정리한다. 성공한 파일과 원본은 삭제하지 않는다. 결과 파일 이름 충돌은 고유 이름으로 처리한다.

서버는 루프백 주소에만 바인딩한다. 쓰기 API는 허용한 로컬 Origin과 세션 토큰을 확인한다. 브라우저가 보낸 임의 경로 대신 서버가 발급한 자산/프로젝트 ID만 접근한다. 가져온 상대 경로가 저장 디렉터리를 벗어나지 않게 검사한다. FFmpeg는 셸 문자열이 아닌 인자 배열로 실행한다. 사용자 자산이나 가사를 외부 서버에 전송하지 않는다.

## 오픈소스 제공 범위

코드는 MIT 라이선스를 기본 제안으로 한다. README에 설치·실행·FFmpeg 요구 사항·가사 예시·프로젝트 저장 위치·내보내기 방법을 기재한다. 사용자 MP3, 영상, 로컬 프로젝트와 렌더 결과는 Git 추적에서 제외한다. 데모가 필요하면 직접 생성한 짧은 음원과 직접 작성한 가사만 사용한다. 의존성/폰트/외부 도구의 라이선스는 별도 고지한다. 공개 저장소 생성과 게시 자체는 이 설계 승인에 포함하지 않는다.

## 완료 기준과 검증

1. 폴더 내 MP3 목록에서 곡을 선택해 실제 재생·일시정지·탐색할 수 있다.
2. 가사 구간 경계, 공백, 처음/끝, 탐색 후 시점을 자동 테스트로 검증한다. 겹침·잘못된 숫자·범위 초과는 거부한다.
3. 사진/영상 변경과 스타일 조절이 미리보기에 반영되고, 배경 영상은 반복되며 원본 오디오는 들리지 않는다.
4. 저장 후 앱을 재실행해 자산과 편집 상태를 복원한다.
5. 짧은 검증용 음원으로 사진 배경과 반복 영상 배경 각각 MP4를 실제 출력한다. ffprobe로 해상도·프레임률·코덱·오디오 존재·길이(오차 0.1초 이내)를 확인한다.
6. 출력 영상을 재생하고 가사 경계 전후와 중간 시점의 프레임을 확인한다. 미리보기와 같은 시점에서 가사·배치·배경이 일치하는지 검증한다.
7. 수분 길이 곡을 한 번 출력해 끝까지 완료되는지, 메모리/임시 공간이 무제한 증가하지 않는지 확인한다. 취소 후 재시도가 가능해야 한다.
8. 한글/일본어/영문, 긴 가사, 빈 가사, 배경 없음, 잘못된 파일의 UI를 확인한다.
